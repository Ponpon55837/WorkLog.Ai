# Work Intelligence report writing

Read the canonical Work Intelligence format before writing. This skill improves wording; it does not authorize reading untracked projects, rewriting historical records, or changing facts.

Choose one language guide on demand:

- English: [references/en.md](references/en.md), or MCP resource `work-intelligence://agent/worklog-report-writing/references/en.md`.
- Traditional Chinese: [references/zh-TW.md](references/zh-TW.md), or MCP resource `work-intelligence://agent/worklog-report-writing/references/zh-TW.md`.

Start with the outcome and scope. Group related work at the report period's scale. Give each fact one principal home; other sections add evidence or implications instead of repeating it. Keep exact commands, identifiers, numbers, dates, status distinctions and source citations.

Put source coverage in one dedicated risks block: distinguish the request snapshot, eligible sources, fully reviewed sources, current-period totals, and unavailable or omitted sources. The context report retains current-period aggregates and diagnostics; only its selected source arrays and evidence follow the fixed request. Support synthesis claims with fully read Sessions belonging to that request. Cite supporting Sessions. Do not repeat this diagnostic in every section. A preview is a pointer: read full Sessions before making material claims. An omitted fact remains unknown, not successful or irrelevant.

Check every material claim against a source. Preserve qualifications that change its meaning. Prefer short sentences and specific verbs, but never remove evidence to meet a length target. Do not apply this skill to simple retrieval, metadata backfill, or Knowledge maintenance. Do not certify ASD-STE100 compliance from these guidelines.
