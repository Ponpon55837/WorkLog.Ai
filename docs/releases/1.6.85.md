# Work Intelligence 1.6.85 更新說明

應用程式與 Agent plugin 版本為 1.6.85。schema 維持 40，不需要升級資料庫。

這一版簡化 Agent 更新知識頁的流程，減少 Agent 要額外呼叫或被拒後整頁重做的情況（#467）。

## 存檔時就能標記已檢查

以前 Agent 更新知識頁要三步：讀取上下文、存檔、再標記已檢查，頁面才會變成最新。現在存檔時可以一併標記，兩步就完成。沒有一併標記時，存檔結果會提醒涵蓋範圍還沒推進。

## 來源超過 20 筆不再整份拒絕

一個段落引用超過 20 筆來源 Session 時，以前整份存檔都會被拒絕，Agent 只能自己刪來源再重送。現在會保留最新的 20 筆，並在結果中列出被捨棄的來源。網頁上的編輯器仍維持 20 筆上限。

## 存檔衝突時附上重試資料

存檔時如果頁面已被別人更新，結果會附上新的讀取憑證和有變動的段落，Agent 只要重新套用自己的修改，不必整頁重讀。

## 標記已檢查只回傳精簡結果

標記已檢查以前會回傳整頁內容，現在只回傳版本、狀態和涵蓋範圍，減少 Agent 的讀取量。

## 還沒完成的工作不算進知識頁

開工記錄（還沒完成的工作）不再算進知識頁的新 Session，工作還沒做完，頁面就不會被列為有新資料。完成之後才會計入。
