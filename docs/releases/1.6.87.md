# Work Intelligence 1.6.87 更新說明

應用程式與 Agent plugin 版本為 1.6.87。資料庫升級到 schema 42，開啟時會自動升級，升級前會先備份。

這一版修正知識頁的誤判，以及兩台電腦互相匯入時無法解決的衝突（#475、#477、#479）。

## 知識頁不再因為加關聯而要求核對

以前知識頁引用的 Session 只要被後來的工作接續、加了相關 Session、附上證據，或圖表被作廢、還原，知識頁就會顯示「來源需要核對」，但內容其實沒變。現在只有 Session 的標題、摘要、工作摘要、檔案、驗證結果、時間等內容改了，或 Session 被作廢、還原時才會提示。

升級時會清掉以前因為這些情況留下的提示。少數已隱藏或延後的待處理項目，升級後可能會再出現一次。

## 兩台電腦互相匯入時，決策會以 Session 摘要為準

一台電腦改寫了某筆 Session 的決策後，另一台匯入時，以前新的決策會被列成「唯一識別值已被另一筆資料使用」並略過，舊的決策會一直留著，兩台電腦的內容不一致。

現在匯入時會把每筆 Session 的決策當成一組，和 Session 摘要裡記的決策比對：

- 匯入檔和摘要一致、本機不一致時，用匯入檔的決策取代本機過時的決策。匯入預覽會顯示「取代本機過時決策」的筆數，匯入前會先備份。
- 本機和摘要一致時，保留本機的決策，不再列成衝突。
- 兩邊都不一致時，和以前一樣列成衝突。

被取代的決策若已升級成 Knowledge 或被 Agent 審查引用，Knowledge 和審查紀錄都會保留。已經不一致的兩台電腦，各匯入一次對方的匯出檔就會一致。

## 永久刪除 Session 後不再留下匯入衝突

永久刪除一筆 Session 後，它處理過的其他 Session 的待結項紀錄仍會指向它，另一台電腦匯入時這些紀錄每次都會被列成衝突。現在只要那筆 Session 在匯入檔和本機都不存在，就照原樣匯入。
