# Work Intelligence 1.6.84 更新說明

應用程式與 Agent plugin 版本為 1.6.84。schema 維持 40，不需要升級資料庫。

## 選了專案後可以直接切換到其他專案

以前在工作知識頁選了某個專案後，專案選單只剩「所有記錄中的專案」和目前的專案，要先切回全部才能選別的專案。

現在每個頁面的專案選單都用同一個元件，固定列出所有可選的專案，不管目前選的是哪一個：

- 工作知識：Knowledge 清單、知識頁、候選、Agent 審查請求
- Session 與未結項、報告、圖表、需要注意的事項、Agent 讀取、補登資料

列出全部專案的選單（例如 Session）顯示「所有專案」，只列記錄中專案的選單顯示「所有記錄中的專案」。

## 輸入錯誤會指出實際出錯的欄位

有些欄位接受兩種格式，例如結案時的決策可以是一句文字，也可以是帶來源的物件。以前兩種格式都不符時，錯誤只寫「Invalid input」，看不出是哪個欄位錯。現在 MCP 與 REST 都會指出實際的欄位和可用的值，例如：

`decisions.0.origin: Invalid option: expected one of "user_requested"|"agent_autonomous"`

## 匯入檔案時不再把相同的 Session 關聯算成衝突

1.6.83 修正後，用 App 匯入檔案或用 CLI 匯入時，已存在的相同 Session 關聯仍會顯示一筆「唯一識別值」衝突。現在讀檔匯入也會正確略過；只有關聯類型不同時才會列為衝突（#471）。
