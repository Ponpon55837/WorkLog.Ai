# Work Intelligence 1.6.1 更新說明

日期：2026-10-19。應用程式與 plugin 版本為 1.6.1；資料庫 schema 維持 30。

## 架構圖閱讀器重畫

- **依連線方向排版**：沒有指定座標的卡片，會以群組為區塊、依群組之間的連線由左到右排成欄；同一欄的多個區塊上下堆疊並置中，群組內再依內部連線分小欄。遇到循環時，從最先宣告的節點開始。畫面不再往右下角斜著延伸，空白少很多。
- **直角連線**：依兩張卡片的相對位置選擇面對的邊連接，轉角為圓角。共用同一邊的多條連線會錯開連接點；路徑會繞過中間的卡片，平行的線段各走各的通道，並優先選交叉與轉折最少的路徑。
- **看得到連線標籤**：`edge.label` 直接顯示在線上（過長會截短，完整文字在提示中）。
- **群組顏色**：每個群組分到六種主題色之一，用在群組框、卡片與從它出發的連線；明暗主題都達 WCAG AA。滑過、聚焦或選取卡片時，相關連線會變亮，其他連線變淡。
- 作者指定的 `position` 一律保持不動，自動排版的卡片不會壓到它們。

## 不變的部分

只改前端。架構圖 JSON 格式、資料庫 schema（30）與 MCP 契約都沒有變更，Agent 不需要重新連線。
