# Work Intelligence 1.6.83 更新說明

應用程式與 Agent plugin 版本為 1.6.83。schema 維持 40，不需要升級資料庫。

## 開工記錄的開始時間不再被覆寫

Agent 開工時留下開工記錄、收尾時用同一個 key 再結案一次，就能原地完成同一筆 Session。以前開工與收尾之間如果 MCP 重新啟動（例如升級後重新連線），收尾後的開始時間會變成重啟後的時間，原本說明開始時間來源的紀錄也會被換掉。

現在收尾時沒有另外傳入開始時間，就沿用開工記錄的開始時間與它的來源紀錄。明確傳入的開始時間仍然優先。

## 匯入時同一筆 Session 關聯不再算衝突

以前收尾改寫開工記錄時，Session 之間的關聯會換一個新 ID。另一台電腦匯入過開工時的資料，再匯入收尾後的匯出檔，預覽會出現「唯一識別值已被另一筆資料使用」的衝突。

現在改寫時保留原本的關聯 ID；匯入時遇到同一對 Session、同一種關聯，只是 ID 不同，會直接略過，不算衝突。關聯種類不同時仍然列為衝突。
