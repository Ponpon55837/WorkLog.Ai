# Work Intelligence 1.6.36 更新說明

日期：2026-11-14。應用程式與 plugin 版本為 1.6.36；資料庫 schema 維持 33，沒有 schema 變更，也不需要 migration。

## 摘要

這一版是 Web UI 的外觀改版：沿用現有的藍色，精修配色 tokens，拿掉英文大寫小標（eyebrow），並重新排版總覽、工作歷程、工作知識、工作圖譜與工作報告。版面行為不變：固定高度、區塊內捲動、sticky 工具列與標題列、分頁列固定在卡片底部、側邊面板與對話框的捲動、換頁回到頂端，全部保留。資料、API 與 MCP 行為不受影響。

產品方向不變：有效沉澱 → 精準再利用 → 持續修正。

| 問題 | 改版前的現象 | 這一版 |
| --- | --- | --- |
| 同樣的元件各寫一份 | 側邊面板標題列、數字卡格線與主欄加側欄版型，各在 6 個地方重複寫，間距與斷點也不一致 | 收斂為共用元件：`UiSidePanelHeader`、`UiStatGrid`、`UiSplitLayout` 與 `UiStack`；連結樣式改用 `UiButton` 的 link 變體；手刻數字卡與進度條改用 `UiStatCard` 與 `UiMeter` |
| 未定義的顏色 token | 總覽洞察的提醒文字使用 `--fg-attention`，但 tokens 沒有定義，所以顏色不生效 | 改用已定義的顏色 |
| 圖譜時間軸字級過小 | 時間軸標籤為 10px，低於規範的 12px 最小值 | 最小 12px |
| 小標與配色 | 英文大寫小標重複出現；深色主題的次要文字對比偏低 | 拿掉小標，只留標題；精修 tokens（表面層、兩級圓角、on-accent 文字色）；修正深色次要文字對比 |

## 改版內容

### 總覽

- 工作熱度維持在最上面，仍顯示近 53 週，每格一天。
- 「本週的循環」依序顯示記錄、沉澱、修正：本週記錄的 Session 數、新增的 Knowledge 數、知識頁更新數，以及確認與推翻次數。只放產品現在算得出來的數字。
- 「本週完成」卡附八週的每週完成 Session 走勢。

### 工作歷程

- Session 依時間軸排列，每天一段整日小結（筆數、通過與驗證失敗的筆數），並顯示當天新增的 Knowledge 數。

### 工作知識

- 每則 Knowledge 的信任條只由確認與推翻次數畫成，點開仍可看到來源 Session。
- 可能過時的原因移到標題下方，標籤退為次要資訊。
- 新增「類型分布」，顯示目前專案與狀態下各類型的數量；搜尋與類型篩選不影響這些數字。

### 工作圖譜（時間軸）

- 每天一根中性色長條，失敗的工作以紅色標示。（1.6.37 已改回依驗證結果上色。）
- 新增的 Knowledge 以強調色菱形標示；確認與取代為空心菱形；推翻為叉號。
- 日寬足夠時，週末以底色標示；專案名稱固定在左欄。

### 工作報告

- 總覽的每日分布改為直條。
- 還沒有 AI 整理時，以一行橫幅與按鈕取代整張卡片。
- 專案占比改為依專案堆疊的條狀圖；帶時段的條列說明本期發生的事。

### 其他頁面

- 專案、系統狀態、Session 側邊面板，以及圖譜的關係圖與熱點，套用同樣的外觀規則，版面結構不變。
- 專案匯出與匯入的控制項，與報告工具列的控制項尺寸一致。
- 側欄的群組標題（工作、知識、管理）依介面語言顯示。

## 沒有做的項目

以下項目目前沒有真實資料，或會改變行為，這一版不做，也不以假數字或估計值代替：

- 沒有資料：「幾筆工作引用過去知識」、知識的「未回報」次數。
- 屬於行為變更：「本週標為過時」、專案迷你走勢、「放了幾天」、「最久排最前」、「依最近確認排序」。

## 驗證

- `pnpm format:check`、`pnpm lint`、`pnpm typecheck`、`pnpm build`：通過。
- `pnpm test`：全部套件通過（web 41 個檔案 211 項；storage 95 個檔案 934 項另有 1 項預期失敗；其餘套件皆通過，略過 2 項）。
- `pnpm test:coverage`：通過，門檻沒有放寬；web 行覆蓋率 90.26%。
- E2E 加 `--trace off`：chromium 196 項通過、1 項略過；firefox 138 項通過；webkit 120 項通過。包含 `accessibility-states.spec.ts` 的 axe 檢查（zh-TW 與 en-US）。
- `pnpm test:start-smoke`：5／5 通過。
- 版面行為對照：用同一份虛構種子資料，在 1440×900、1440×600、390×844 三種視窗量測 main（1.6.35）與本分支的 19 個畫面，共 57 列、735 個適用格，617 格相同、118 格不同。46 列有差異，逐張比對截圖後都判定為內容重組造成的外觀差異，沒有行為退步。分頁器位置、卡片內捲動、水平捲動、換頁回到頂端與側邊面板捲動全部相同。另有兩處差異請留意：
  - 工作報告總覽的「專案占比」由卡內可捲的虛擬清單改為緊湊清單，卡片不再撐到視窗底，但所有專案都看得到。
  - 手機寬度的工作知識清單下方多了「類型分布」卡，因此整頁可以捲動。清單本身的捲動、分頁器與 sticky 工具列不變。
  - 報告系列的 sticky 工具列與表頭因工具列變高，黏住後的位置下移約 3.5px。

## 未驗證與已知限制

- README 截圖已用新畫面與虛構示意資料重拍（zh-TW、en-US 各 8 張）。英文版「系統狀態」的 MCP 狀態句與「工作報告」的期間摘要句仍是中文；這兩句由 server 端產生，不在這次改版範圍內。
