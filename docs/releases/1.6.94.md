# Work Intelligence 1.6.94 更新說明

應用程式與 Agent plugin 版本為 1.6.94。資料庫維持 schema 43。

這一版整理工作知識的「待確認決策」（#487）。

## 按鈕分清主次

每筆決策只有「確認」是主要按鈕，「拒絕」是一般按鈕，「整理成 Knowledge」收進「更多」選單。處理完一筆後，焦點會移到下一筆。

## 確認立即生效，拒絕先詢問

人工確認或拒絕的決策無法退回「待確認」，所以沒有「復原」：「確認」立即生效，「拒絕」不論單筆或批次都會先詢問。詢問期間如果有決策已在別處處理過，就會略過它，不會覆蓋，提示訊息會說明略過幾筆。總覽「需要處理」裡的「拒絕」也一樣。

## 一次處理多筆

每筆決策都可以勾選，勾選後才出現「確認所選」與「拒絕所選」，規則和未結項相同。清單最多顯示 200 筆（原本 50 筆）。

## 整理成 Knowledge 更順手

內容會先帶入決策文字，游標停在內容；標題留空，並提示寫成別人搜尋得到的結論；不再預設標籤。

## 更容易找到

沒帶分頁打開工作知識時，有待確認決策就先顯示它，沒有就顯示 Knowledge。Knowledge 清單的網址改為 `/knowledge/list`，舊的 `/knowledge?q=…` 連結會自動轉過去。側欄「工作知識」顯示所有專案的待確認決策與候選數量。
