# Work Intelligence 1.6.101 更新說明

應用程式與 Agent plugin 版本為 1.6.101。資料庫維持 schema 43。

這一版讓 Agent 看得到完整的既有知識清單，避免重複提出（#474 第四步）。

## 既有知識改成精簡清單

Agent 審查（`work_get_agent_review_context` 第 1 頁）與知識候選整理（`work_get_knowledge_candidate_context`）都會附上專案既有知識的標題，讓 Agent 不重複提出已有、已封存或已駁回的內容。以前每筆都帶 id 與種類欄位，又有固定筆數上限，知識一多就有一大段放不進來。

現在標題依狀態（有效、已封存、已駁回、待審）與種類分組，不帶 id，同組相同標題只列一次；筆數上限提高為有效 300、已封存 100、已駁回 50。放不下時優先保留待審、已駁回與已封存的標題，因為這些最容易被重複提出；剩下的數量仍列在 `existingKnowledgeOmitted`。回應上限沒有改變。

用真實資料實測：既有知識從列出 152 筆、漏掉 89 筆，變成 241 筆全部列出；審查第 1 頁從約 23,800 字元降為約 16,100 字元，完整審查一次（6 頁）從約 61,300 降為約 53,500 字元。
