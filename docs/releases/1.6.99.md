# Work Intelligence 1.6.99 更新說明

應用程式與 Agent plugin 版本為 1.6.99。資料庫維持 schema 43。

這一版讓 Agent 維護知識頁時少一次來回（#474 第二步）。

## 需要整頁時直接回整頁

Agent 以「只看要複查的段落」（`reviewOnly`）讀取知識頁時，如果伺服器判定這頁大部分段落都要複查，或頁面還沒寫過、使用者要求重寫，以前只會回覆「請改用整頁讀取」，Agent 得再呼叫一次。

現在同一個回應就是整頁讀取的內容：頁面、Session 預覽（包含 `sessionsSeenIn` 省略的摘要）與可用來存檔的 `reviewToken`，另外標明是哪一種情況。回應大小與整頁讀取相同，沒有提高任何上限；其他情況（只需看幾個段落、沒有要處理的、內容太多需分批）照舊。

用真實資料實測維護五個知識頁，從 10 次呼叫、約 63,600 字元降為 5 次呼叫、約 58,400 字元。
