# Work Intelligence 1.6.81 更新說明

應用程式與 Agent plugin 版本為 1.6.81。資料庫維持 schema 39。升級後請重新連線 MCP，Agent 才會讀到新的伺服器說明。

## 工作知識分頁照處理順序排列

工作知識的四個分頁改為「待確認決策 → 候選 → Knowledge → 知識頁」，和項目從待確認、接受到整理進知識頁的順序一致。開啟工作知識時仍預設顯示 Knowledge。

## 交給 Agent 的說法寫明 Work Intelligence

Web 上提示你對 Agent 說的話，原本是「處理 Agent 審查請求」「整理 Knowledge 候選」「更新知識頁」。沒有上下文的 Agent 可能把「審查請求」當成 PR review。現在都改成帶工具名稱的說法：

- 「用 Work Intelligence 處理 Agent 審查請求」
- 「用 Work Intelligence 整理 Knowledge 候選」
- 「用 Work Intelligence 更新知識頁」
- 整理未結項的提示也改成「請 Agent 用 Work Intelligence 整理……」

MCP 的伺服器說明新增一句，把這幾種要求對應到各自的指南。Agent skill 的描述也列出這三種工作。
