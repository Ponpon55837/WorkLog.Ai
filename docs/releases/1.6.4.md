# Work Intelligence 1.6.4 更新說明

日期：2026-10-28。應用程式與 plugin 版本為 1.6.4；資料庫 schema 維持 30，不需 migration。

## Agent 引用規則

- work_recall、work_search 與 work_get_context 的工具說明、契約、work-intelligence skill 與 docs/mcp-tools.md 新增規則：讀完來源後，只有來源直接支持答案時才引用；否則明確回答「資料不足」，不可依字面相似、confidence、排名或時間先後推論。舊版只要求引用前讀完整紀錄。
- 排序、confidence、回應格式與 schema 均未改變；私有評估的 recall 與 context 指標前後相同。

## 檢索評估

- pnpm bench:recall-scale 另外量測「只出現在 raw handoff 的答案」放進獨立候選清單時的排名，不改變 recall 輸出。私有評估中這些候選沒有補回任何漏失答案，且增加延遲，因此 recall 不採用。
- 新增答案性測試：字面相似但有答案或無答案、部分相關、紀錄互相矛盾、Knowledge 已封存、Session 已作廢或已還原，以及用結果 id 讀取完整來源、並檢查工具說明要求回答「資料不足」的決定性 MCP 流程。另以預期失敗測試記錄已知限制：沒有連結的較新 Session 不會排在較舊的 Session 前面。

## 升級

1. 在舊版目錄執行 pnpm check 並記下資料庫位置；可先執行 pnpm db:backup。
2. 取得 1.6.4 原始碼後，在新版目錄執行 pnpm install --frozen-lockfile、pnpm build 與 pnpm check。
3. 保留既有資料庫檔案與 WORK_INTELLIGENCE_DB，確認新版指向相同的資料庫絕對路徑。
4. 執行 pnpm start 並確認 Dashboard 與 /api/health 正常；重新連線 Codex／Claude，讓 MCP 載入新的工具說明。若已安裝 Agent skill，依 pnpm start 的過期提醒更新。

完整流程與 schema 相容性限制見發行與升級指南（docs/release.md）。
