# Work Intelligence 1.6.35 更新說明

日期：2026-11-14。應用程式與 plugin 版本為 1.6.35；資料庫 schema 維持 33，沒有 schema 變更，也不需要 migration。

## 摘要

這一版是無障礙與測試穩定性的整理，產品方向不變：有效沉澱 → 精準再利用 → 持續修正。主要改動是讓無障礙名稱與畫面上的可見文字一致，並把 axe 檢查擴大到對話框、開啟的選單與行動版側欄。資料內容與 schema 不受影響。

| 問題 | 量到的現象 | 這一版 |
| --- | --- | --- |
| 無障礙名稱與可見文字不一致（WCAG 2.5.3 Label in Name） | axe-core 4.14 將 `label-content-name-mismatch` 列為 serious；部分控制項的名稱與畫面文字不同，或沒有名稱 | 名稱改由可見文字產生；表單控制項的名稱等於可見欄位標籤 |
| axe 檢查範圍不足 | 既有檢查未涵蓋命令面板、Session 側欄、Knowledge 編輯器、刪除專案對話框、開啟的選單與行動版側欄 | 新增 `tests/e2e/accessibility-states.spec.ts`，在 zh-TW 與 en-US 下檢查這些狀態 |
| 固定毫秒上限的時間測試不穩定 | 固定毫秒上限受機器速度與負載影響 | 共用 helper 依同一行程內的參考工作量放大上限；門檻沒有放寬 |

## 無障礙名稱（WCAG 2.5.3）

axe-core 4.14 將 `label-content-name-mismatch` 列為 serious。本版的修正讓無障礙名稱以可見文字開頭，或完整包含可見文字：

- 架構圖節點按鈕移除 `aria-label`，名稱由可見標籤、說明、群組與檔案名稱組成。
- 標題列搜尋按鈕的名稱來自可見文字；快捷鍵以 `aria-keyshortcuts` 提供，`kbd` 設為 `aria-hidden`。窄螢幕上文字改為視覺隱藏而非 `display: none`，名稱不會變成空字串。標題列 logo 以「WI」加上視覺隱藏的「Work Intelligence home」取代 `aria-label`。
- 圖形畫布節點的標籤與說明合併為同一段文字，中間加入真正的空白，使可見文字包含在名稱中（英文單字先前會黏在一起）。
- Knowledge 證據按鈕、變更檔案的「Open in editor」連結，以及未結項的來源 Session 按鈕，名稱都以可見文字開頭。
- 日曆日期按鈕以介面語言的完整日期命名（例如 "November 5, 2026"、"2026年11月5日"），不再使用 ISO 字串。
- 表單控制項的名稱等於其可見欄位標籤：系統狀態編輯器的 select、備份匯出與匯入的 select、Knowledge 編輯器的類型與狀態，以及刪除專案的確認輸入框。刪除確認改用欄位標籤，並以專案名稱作為提示。
- `UiTextInput` 不再在 `UiField` 內渲染巢狀 `<label>`；先前欄位內的輸入框沒有標籤（axe `label` 規則）。
- 非本月的日期不再使用 opacity，符合 WCAG AA 對比。
- 側欄圖示列（640–959px）以視覺隱藏標籤保留連結名稱，不再使用 `display: none`。

## 新增的無障礙 E2E 檢查

`tests/e2e/accessibility-states.spec.ts` 以 axe 檢查 critical 與 serious 規則，範圍包括：命令面板、Session 側欄、Session 編輯器、Knowledge 編輯器與刪除專案對話框；已開啟的選單（語言、專案篩選、日期範圍日曆）；行動版側欄抽屜。以上在 zh-TW 與 en-US 兩種語言下執行，另外檢查 en-US 的主要頁面。

## 測試穩定性

共用 helper `tests/helpers/timing.ts` 以同一行程內、同樣大小的參考工作量計時，並依此放大固定毫秒上限。倍率限制在 1 到 8 之間，且不低於原本寫定的上限。套用對象為交接解析器，以及兩個秘密遮蔽的線性時間測試。倍增比例檢查改為交錯執行半量與全量的測試。暫時加入的二次方退化被確認會讓這些測試失敗。沒有放寬任何門檻。
