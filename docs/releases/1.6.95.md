# Work Intelligence 1.6.95 更新說明

應用程式與 Agent plugin 版本為 1.6.95。資料庫維持 schema 43。

這一版讓工作知識的知識頁與 Knowledge 清單更好讀（#488）。

## 知識頁內文分段

側邊面板會依換行把每一節分成段落，以 `-`、`*`、`•` 或 `1.` 開頭的連續行顯示成清單，行寬約 72 字。舊頁面的段落只剩句號加空白時也會在那裡分段；仍然太長的段落會在句尾切開，不會切在括號、版本號或路徑中間。內容一律當純文字顯示。

## 來源收合

每一節的來源收進「來源（N）」，展開後一行一筆，先顯示前 3 筆，其餘按「顯示全部」再看。

## 知識頁依專案分組

沒有篩選專案且有兩個以上專案時，知識頁分頁會依專案分組；同名專案會加上資料夾名稱，不同專案的同名頁面也分得清楚。專案名稱不再擠在資訊列裡。已寫好的頁面點標題就能打開，和「查看」一樣。

## 自訂知識頁

只要有追蹤中的專案就能按「自訂知識頁」。沒有選專案而追蹤了多個專案時，對話框會先請你選要建在哪個專案。

## Knowledge 列更精簡

Knowledge 每列預設只顯示標題、類型、一行摘要和一行資訊，一個畫面能看到更多筆。按「展開詳情」才顯示全文、標籤、參考資料與適用路徑，鍵盤也能操作。
