# Work Intelligence 1.6.37 更新說明

日期：2026-11-14。應用程式與 plugin 版本為 1.6.37；資料庫 schema 維持 33，沒有 schema 變更，也不需要 migration。

## 這一版修正什麼

1.6.36 把工作圖譜時間軸的長條改成灰色，只有驗證失敗保留紅色。這讓「驗證通過」和「未執行」看起來一樣，也和產品其他地方「通過用綠色」的規則不一致。這一版改回來。

- Session 長條與每日長條依驗證結果上色：驗證通過是綠色，驗證失敗是紅色，進行中是藍色，未執行或未提供是灰色。
- 圖例恢復列出這四種結果。
- 1.6.36 的其他調整保留：週末底色、固定在左側的專案名稱欄，以及 Knowledge 事件用形狀區分（新增是實心菱形，被確認或取代是空心菱形，被推翻是叉號）。

## 不變的部分

沒有資料、API 或 MCP 行為變更。版面與捲動行為不變。

## 升級

1. 取得 1.6.37 原始碼後重新建置並重新啟動。
2. 不需要 migration，也不需要重新匯入資料。
