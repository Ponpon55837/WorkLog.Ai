# Work Intelligence 1.6.97 更新說明

應用程式與 Agent plugin 版本為 1.6.97。資料庫維持 schema 43。

這一版整理網頁介面的操作細節（#490）。

## 搜尋看得到符合的地方

工作歷程搜尋會在標題與摘要中標出符合的字詞。符合的地方不在畫面上的文字裡時，列表多一行摘錄，例如「摘要：…」「成果：…」「決策：…」；只有工作事件符合時顯示「符合工作事件」。手機上摘錄從符合處附近開始，最多兩行。搜尋框提示改為「搜尋標題、摘要或事件」，每頁預設 20 筆。

## 手機上更好讀

- 工作歷程、工作知識與知識頁清單在手機上跟著整頁捲動，不再擠在小小的捲動框裡。
- Session 詳情的耗時另起一行，開始與最後更新時間收進「開始與最後更新」；執行狀態顯示「已完成」，驗證欄位標為「驗證」。觸控裝置不再顯示 J/K 快捷鍵提示。
- 分頁列在還有隱藏分頁的那一側淡出。

## 關係圖記得上次的專案

網址沒有指定專案時，關係圖開啟上次選的專案，沒有的話開啟最近有 Session 的追蹤專案；「全部專案」也會被記住。專案清單載入失敗時會顯示「重試」。節點數量、預覽大小與「推導的關係」收進「顯示設定」。

## 其他

- 系統狀態把「個人偏好」移到最上方。
- 資料夾不在這台電腦的專案改顯示中性的「不在這台電腦」，清單上方說明不影響閱讀；無法確認資料夾時仍另外標示。
- `/projects/backups` 與 `/projects/deletions` 會轉到正確的分頁。
