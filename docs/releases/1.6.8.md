# Work Intelligence 1.6.8 更新說明

日期：2026-11-07。應用程式與 plugin 版本為 1.6.8；資料庫 schema 維持 31，不需要 migration。Node.js 需求改為 22.16 以上的 22.x 或 24 以上（不支援 23.x）。

## 修正

- **Node.js 26.9 以上報告頁打不開**：搜尋索引在刪除舊資料時，FTS5 會寫入編號超過 2^53 的刪除標記，Node.js 26.9 起的 `node:sqlite` 因此拋出 `ERR_OUT_OF_RANGE`，報告、recall 與 Knowledge 候選回 500。已修正寫法；資料與索引都沒有損壞。Node.js 22、24、25 與 26.0–26.7 不受影響。
- **Node.js 最低需求**：22.13–22.15 與所有 23.x 內建的 SQLite 沒有 FTS5，搜尋索引建不起來。需求改為 22.16 以上的 22.x 或 24 以上；`pnpm bootstrap` 會拒絕不支援的版本，`pnpm check` 會實際檢查 FTS5。
- **發行流程安全性**：發佈的一律是各項檢查驗證過的那個 commit；tag 在檢查期間被移動就停止發佈，寫入權限的 token 不再留在 checkout 中。

## MCP 更新後不必重連

- Agent 改經由穩定的 MCP launcher（`apps/mcp/dist/launcher.js`）連線。`pnpm build` 產生新建置後，launcher 會等進行中的請求完成、啟動新版 server 並重播握手，同一個連線直接改用新版；只有 launcher 本身更新時才需要重連。
- Agent 取消的請求不會擋住切換；有請求卡住時只等一次，之後的請求照常由目前的 server 處理。
- `pnpm setup:agents`、plugin 與 `pnpm start:mcp` 都改用 launcher；舊的直接註冊仍可使用，重新執行 `pnpm setup:agents` 即可升級。

## 不需要 checkout 的獨立套件

- GitHub Release 新增 `work-intelligence-<版本>.tgz`：內含 API server、Web 介面、MCP server 與 `work-intelligence` 指令（`start`、`mcp`、`track`、`check`、`db`），只需要 Node.js，不需要 git、pnpm 或 build。
- 同一個 Release 附上 `SHA256SUMS.txt`，列出每個附件的 SHA-256；下載與驗證方式見獨立套件說明（docs/standalone.md）。
- 獨立套件的資料預設在 `~/.work-intelligence/data`；相對的 `WORK_INTELLIGENCE_DB` 以 `~/.work-intelligence` 為基準。checkout 的行為不變。
- 目前不發佈到 npm；Agent 註冊與登入自動啟動服務仍請使用 checkout。

## 效能

- Web 首頁主程式從 514 kB 降到 313 kB（gzip 168 kB → 111 kB）：英文語系與全域面板改成需要時才載入，畫面與行為不變。
- 大量資料同時需要重建搜尋索引時（例如 migration 或遮蔽之後），同步時間約減半。

## 開發與測試

- 發行 workflow 改為三個瀏覽器平行執行 E2E、每個作業系統只跑一次單元測試；tag 指向的 commit 若已在 `main` 通過完整 CI，只重跑生產依賴稽核就發佈。
- CI 新增 Node.js 26 的 storage 測試，以及三個作業系統的獨立套件 smoke test。
- Windows 上 schema 30 快照遷移測試從約 7.7 秒降到 1.3 秒。
- 兩份 README 不再堆疊各版本摘要；版本說明只寫在 CHANGELOG 與本目錄。

## 升級

1. 確認 Node.js 版本：`node --version` 須為 22.16 以上的 22.x 或 24 以上。
2. 取得 1.6.8 原始碼後執行 pnpm bootstrap（或 pnpm install --frozen-lockfile、pnpm build 與 pnpm check）。
3. 若已安裝登入自動啟動服務，執行 pnpm service:restart，確認輸出「服務已在執行 1.6.8」。
4. 執行 pnpm setup:agents 把 Agent 的 MCP 註冊改成 launcher，再重新連線一次；之後的更新就不必再重連。

完整流程見發行與升級指南（docs/release.md）。
