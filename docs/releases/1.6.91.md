# Work Intelligence 1.6.91 更新說明

應用程式與 Agent plugin 版本為 1.6.91。資料庫維持 schema 43。

這一版處理實際整理未結項時遇到的三個不順手（#493）。Agent 需要重新連線才會看到新參數。

## 已檢查的項目可以之後補判定

Agent 整理未結項時，可以先把讀過但證據不足的項目標為已檢查，之後在同一次整理中補上判定，不會再整批被拒絕。所有項目都檢查完後這次整理就會結束；之後才找到證據時，回條會提示重新開一次整理，仍待處理的項目會再列入。這樣補上的判定，匯出到另一台電腦也會保留。

## 寫工作記錄時標出可能重複的未結項

Agent 存工作記錄時，如果新的「下一步」和既有的待處理項目提到同一個 issue（也包含 #483–#490 這類範圍），回條會把那些項目排在最前面並標成可能重複，提醒 Agent 把被取代的舊項目一併結案。

## 取得整理內容可以直接指定專案

使用者在 Web 按了「請 Agent 處理」後，Agent 可以直接用專案路徑讀取這次整理的內容，不必先找出請求編號；沒有進行中的整理時會明確回報。
