# Work Intelligence 1.6.5 更新說明

日期：2026-10-30。應用程式與 plugin 版本為 1.6.5；資料庫 schema 維持 30，不需 migration。

## 任務 context 補上相關線索

- 帶任務的 work_get_context 新增選用的 relevant.supplements：從預算裁切後仍保留、排名最前的 3 個 Session，往外一層補上它們的 parent／related Session，以及它們曾套用的 active Knowledge。最多 4 筆、每個來源最多 2 筆，只放 id、標題、補入原因與 Knowledge 的 possiblyStale／needsReview 標示。
- 補入項是可能相關的線索，不是字面命中或答案證據；需要內容時再讀取來源。預算不足時最先移除補入項，並在 omitted 另外記錄。
- 原本的 relevant.sessions、relevant.knowledge、recall 排序、confidence、輸入規則與 schema 都沒有改變。私有評估中 recall 與 context 指標前後相同；回放的 parent／related 觸及率由 28.3% 升至 37.6%，曾套用的 active Knowledge 由 7.4% 升至 18.5%，超出回應預算的比例維持 2.0%。
- docs/mcp-tools.md 與 work-intelligence skill 已說明這個欄位。

## 升級

1. 在舊版目錄執行 pnpm check 並記下資料庫位置；可先執行 pnpm db:backup。
2. 取得 1.6.5 原始碼後，在新版目錄執行 pnpm install --frozen-lockfile、pnpm build 與 pnpm check。
3. 保留既有資料庫檔案與 WORK_INTELLIGENCE_DB，確認新版指向相同的資料庫絕對路徑。
4. 執行 pnpm start 並確認 Dashboard 與 /api/health 正常；重新連線 Codex／Claude，讓 MCP 載入新的回應欄位。若已安裝 Agent skill，依 pnpm start 的過期提醒更新。

完整流程與 schema 相容性限制見發行與升級指南（docs/release.md）。
