# Work Intelligence 1.6.10 更新說明

日期：2026-11-08。應用程式與 plugin 版本為 1.6.10；資料庫 schema 維持 32，不需要 migration。

## 修正

- **圖表作廢／還原不再覆寫時間**：作廢或還原圖表改在同一個交易內重新讀取後再寫入。已作廢的圖表再作廢一次，會保留第一次的時間與原因；未作廢的圖表再還原一次，不會有任何變更，兩種情況都回傳 `duplicate: true`。狀態真的改變時，圖表所屬 Session 的「最後更新」時間會跟著更新，和作廢 Evidence 的行為一致。
- **finalize 建立關聯時也更新對方 Session**：保存工作記錄時帶 `parentSessionId` 或 `relatedSessionIds`，被關聯的 Session 的「最後更新」時間也會在同一個交易內更新，和事後用 `work_link_sessions` 建立關聯的結果相同。無法建立的關聯與重試保存不會更動任何 Session。
- **build 失敗不再擋住下一次 build**：`pnpm build` 或單獨重建 runtime 套件時，如果編譯或 finalize 失敗，現在會移除自己建立的 `.work-intelligence-build-in-progress`，修正錯誤後直接重跑即可，不需要手動刪除。只有標記內容仍是這次 build 寫入的那一份時才會移除，不會刪掉其他正在進行的 build 的標記。失敗的 build 不會被當成有效的 MCP 版本；行程被強制終止時標記仍會保留。

## 升級

1. 取得 1.6.10 原始碼後執行 pnpm bootstrap（或 pnpm install --frozen-lockfile、pnpm build 與 pnpm check）。
2. 若已安裝登入自動啟動服務，執行 pnpm service:restart，確認輸出「服務已在執行 1.6.10」。
3. Agent 重新連線 MCP 一次即可使用新版。

完整流程見發行與升級指南（docs/release.md）。
