# Work Intelligence 1.6.102 更新說明

應用程式與 Agent plugin 版本為 1.6.102。資料庫維持 schema 43。

這一版修正兩個 Agent 讀寫時白花工夫的地方（#502、#503）。

## 超過最後一頁時明確回空頁

Agent 讀取審查內容（`work_get_agent_review_context`）或未結項清理內容（`work_get_outstanding_cleanup_context`）時，以前要求的頁碼超過總頁數，會再回一次最後一頁；Agent 若以「回到空頁」判斷結束，就會重複讀同一頁。現在超出範圍會回空的一頁，頁碼維持原本要求的數字，並標明沒有下一頁。

## 內容沒變的段落不再建立新版本

Agent 更新知識頁時，若送出的段落與目前內容完全相同（標題、內文、來源都一樣），以前仍算成「已取代」並多建一個版本。現在這些段落會列為「沒有變更」；如果整次儲存都沒有實際變更，而且這些段落也不需要複查來源，就不會建立新版本，只會照要求推進檢查位置。來源有更新、需要複查的段落，原樣存回仍代表 Agent 已核對來源，照常建立新版本。

用真實資料副本實測：審查請求共 7 頁時要求第 99 頁會回空頁；把常見陷阱頁的一個段落原樣存回兩次，版本號維持不變。
