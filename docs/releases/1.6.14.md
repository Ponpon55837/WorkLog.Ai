# Work Intelligence 1.6.14 更新說明

日期：2026-11-10。應用程式與 plugin 版本為 1.6.14；資料庫 schema 維持 32，不需要 migration。

## 修正 bootstrap 結尾提示

`pnpm bootstrap` 跑完時，原本每次都提示「在 Agent 重新連線 MCP」，這是 MCP launcher 出現前留下的說法。現在 Agent 註冊的是 launcher，`git pull` 後再執行 `pnpm bootstrap` 時，已連線的 MCP 會在下一個請求前自動切換到新版，不必重新連線。

提示改為：

- 第一次連接 Agent：開新對話或重啟 Agent 載入 MCP；Codex 需在 /hooks 信任 hook。
- 之後更新不必重新連線；只有 Agent 回報 `restartRequired`（例如 launcher 本身更新）時才重新連線一次。

## 升級

1. 取得 1.6.14 原始碼後執行 pnpm bootstrap（或 pnpm install --frozen-lockfile、pnpm build 與 pnpm check）。
2. 若已安裝登入自動啟動服務，執行 pnpm service:restart，確認輸出「服務已在執行 1.6.14」。
3. 不需要重新連線 MCP；MCP 工具與 Agent 契約沒有變更。

完整流程見發行與升級指南（docs/release.md）。
