# Work Intelligence 1.6.98 更新說明

應用程式與 Agent plugin 版本為 1.6.98。資料庫維持 schema 43。

這一版減少 Agent 一次維護多個知識頁時讀取的重複內容（#474 第一步）。

## 不再重複讀相同的 Session 預覽

Agent 一次維護好幾個知識頁時，每一頁讀取維護資料都會附上同一批新 Session 的預覽。現在 Agent 可以把第一次讀取拿到的 `reviewToken` 透過 `sessionsSeenIn` 帶到之後的讀取，第一次已經看過的新 Session 只回傳 ID、標題與相關原因，不再重複整段預覽。

- 第一次讀取時會記下那批 Session 的範圍與預覽的摘要值。之後若其中有 Session 被修改、匯入或作廢，或中間多了新的 Session，這次就不省略，並附上說明。
- 同時也是來源有更新的 Session 仍保留完整預覽；完整讀取一律不省略。
- 格式不對、來自其他專案或沒有記錄新 Session 的 token 會被忽略並附上說明，不影響讀取。

用真實資料實測維護五個知識頁，回應量約少 13,000 字元。
