# Work Intelligence 1.6.46 更新說明

日期：2026-11-17。應用程式與 plugin 版本為 1.6.46；資料庫 schema 維持 33，沒有 schema 變更，也不需要 migration。

## 摘要

本版修正發行流程。1.6.45 的發行流程已建置三個平台的桌面安裝包，打包後的煙霧測試也都通過，但在建立 GitHub Release 前的檢查失敗，所以 1.6.45 只有 tag，沒有 Release。1.6.46 的桌面 App 內容與 1.6.45 相同，並以本版作為第一個附上桌面安裝包的 Release。

- **發行檢查**：`upload-artifact` 會保留檔案在樣式第一個萬用字元之下的路徑，所以合併下載後，安裝包位於 `<platform>-<arch>/out/` 子資料夾，名稱比對失敗。現在發行流程先把所有安裝包移到同一層資料夾再檢查；兩個安裝包同名時直接失敗。`SHA256SUMS.txt` 與 Release 的檔名因此是單純的檔名。
- **打包指令**：`pnpm package:desktop -- --dir` 原本因 `--` 分隔符號被原樣傳入腳本而失敗（`Unexpected argument`）。現在會略過開頭的一個 `--`；`pnpm package:desktop --dir` 照常可用。

## 驗證

- 以失敗那次 run 的實際目錄結構在本機執行修正後的檢查：5 個安裝包時通過並攤平；有同名檔案時以結束碼 1 失敗。
- `tests/server/release-preparation.test.ts` 與 `tests/server/workflow-security.test.ts` 通過。
- `node apps/desktop/scripts/package.mjs -- --skip-build --arch bogus` 與不加 `--` 時，都進到同一個參數檢查（修正前加 `--` 會出現 `Unexpected argument`）。

## 不變的部分

沒有 schema 變更（33），沒有 migration。桌面 App、CLI、MCP 與 HTTP API 的行為與 1.6.45 相同。1.6.45 的已知限制都仍適用，見 [1.6.45 更新說明](1.6.45.md)。

## 升級

1. 不需要 migration，也不需要重新匯入資料。
2. 安裝包沒有 Developer ID 簽章、沒有公證，也沒有自動更新（ADR-38）。請只從官方 Releases 下載，並核對 `SHA256SUMS.txt`；也可以在自己的電腦上以 `pnpm package:desktop` 打包。
