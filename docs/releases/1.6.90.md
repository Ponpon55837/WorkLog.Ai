# Work Intelligence 1.6.90 更新說明

應用程式與 Agent plugin 版本為 1.6.90。資料庫維持 schema 43。

這一版調整 Web 的篩選與總覽「需要處理」（#485、#483）。

## 篩選看得到目前套用了什麼

- 篩選選單的按鈕直接顯示套用的值，例如「專案：某專案」；值太長時會截斷，滑過可看全名。手機上只顯示圖示與小圓點。
- 工作歷程、工作知識、未結項與知識頁的清單上方列出每個套用中的篩選，可逐一移除或一次「清除篩選」。
- 工作歷程與工作知識分頁在篩選時顯示「篩選後 / 全部」筆數。
- 工作圖譜、工作報告、補登資料與 Agent 讀取改用同一個專案篩選選單。

## 總覽的「需要處理」更好處理

- 有待處理項目時，「需要處理」排在統計卡之前；點「待處理」統計卡會跳到這個區塊。
- 每頁 10 筆。同一專案、同一類的項目合併成一列，可展開看前 3 筆；同時篩選專案與類型時不合併。
- 待確認決策可以直接在總覽確認或拒絕；「前往處理」會開到工作知識並標出那一筆決策。
- 專案有進行中的 Agent 請求時，該專案的決策標成「等待 Agent」。
- 筆數上限提示縮成一行，並連到對應的頁面。
