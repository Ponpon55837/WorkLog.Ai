# Work Intelligence 1.6.57 更新說明

日期：2026-11-19。應用程式與 plugin 版本為 1.6.57。資料庫 schema 仍為 33，沒有 schema 變更，不需要 migration。

## 摘要

本版是最後一個 V1 修補版，處理 1.6.55 獨立審查（`docs/desktop/desktop-v1-review-1.6.55.md`）在 1.6.56 之後剩下的中、低嚴重度項目。

- 更換資料庫、更換連接埠、複製到本機磁碟與儲存位置判定，現在都先問後端是否正在匯入、備份或匯出，再經同一個閘與操作協調器停止後端，不會無預警中斷進行中的工作。
- Windows 上結束後端會連同子行程一起結束；後端的關閉寬限（7 秒）小於 App 的寬限。
- 切換資料庫後，頁面會提醒重新開啟 Agent；runtime 資料夾被鎖住時，會說明要先關閉使用它的 Agent。
- Agent 設定可以逐一選擇，其中一個 Agent 設定有衝突，不再擋住另一個。
- 在 Agent 分頁移除 Codex 後再重新設定，不會再顯示「設定衝突」：移除時會一併清掉 Codex 自己加的工具核准表（可還原），重新設定遇到只剩核准表的檔案，會把設定寫在它們前面並保留核准。非 command 形式的註冊（例如 url）仍然不會被改動。
- 還原在 Windows 檔案被鎖時會重試最後的改名，並以完整的 `integrity_check` 檢查；匯入檔開頭的 UTF-8 BOM 會被略過。
- 執行中的後端每分鐘做一次健康檢查，連續三次沒有回應就結束它，由既有的重啟流程接手。

升級不需要任何手動步驟。設定、資料庫與備份都不會因為升級而改變。Windows 11 與 macOS 的實機驗收尚未進行，仍為待實機驗收。

## 修復項目

### 中嚴重度

- **M-01、M-02、M-04** 共用活動閘與協調器（見摘要）；Windows 最後的強制結束帶上整個行程樹。
- **M-03** Windows 工作排程查詢沒有回應時視為「不明」，不再當成「沒有」。
- **M-05** 自動重試遇到鎖定時會再試，仍失敗才顯示。
- **M-07、M-08** 切換資料庫後提醒重新開啟 Agent；runtime 被鎖住時顯示 `RUNTIME_IN_USE` 的說明。
- **M-09** Windows 安裝後第一次啟動不再多讀一次 ACL；檢查失敗時還原前一個指標。
- **M-10** 內建 Node.js 壓縮檔的 SHA-256 已固定。
- **M-13** 新增只在 Windows 跑的測試，把 hook 命令交給 cmd.exe 與 PowerShell。
- **M-14** 還原最後的改名在 Windows 上會重試。
- **M-17** Agent 設定逐一選擇。
- **系統狀態不再誤報 MCP 要重新連線。** 桌面 App 與獨立套件的 MCP 現在內建可驗證的建置識別；狀態頁讀取封裝內的檔案，不再要求 repo 的 `packages/*/dist`。檔案被改動或讀不到時仍顯示「無法確認」。
- **桌面版狀態頁與還原步驟不再出現指令。** 頁面副標、維護結果的空狀態與還原匯出檔的說明，改為指向 App 的「診斷」與「資料」分頁；守護測試擴大到整份網頁語系檔。
- **Agent 卡片能顯示「已連線」。** Agent 分頁現在會讀取 MCP 伺服器在 Agent 實際連線後寫下的觀察紀錄，並與隨 App 附帶的工具契約指紋比對：看到目前契約顯示「已觀察到連線」，舊契約顯示「需重新連線」。之前這份紀錄沒有人讀，Codex 與 Claude Code 即使正常使用，卡片也一直停在「已配置、待確認」。
- **M-18** 匯入略過檔頭 BOM。

### 低嚴重度

L-01、L-02（診斷遮蔽更多路徑）、L-03（桌面 log 權限 0700／0600）、L-04（`launchctl` 固定路徑）、L-06（連接埠確認提到暫存的匯入預覽）、L-07（頁面動作鎖）、L-09（健康檢查）、L-11（Windows USB 硬碟視為可移除）、L-12、L-13（runtime 清理）、L-14（lease 重建）、L-15（複製後 fsync）、L-16（忽略 `.DS_Store` 等檔案管理員雜檔）、L-17（記載 group 可寫為刻意接受）、L-21（設定檔改名重試）、L-22（保留 JSON 縮排與結尾換行）、L-23（匯出邊寫邊計大小，超過 256 MiB 即中止）、L-24（完整 `integrity_check`）、L-25（每小時清理殘留暫存目錄）、L-26（背景處理 30 分鐘 watchdog）、L-27（記載主題差異）、L-28（刪除兩個只有測試用的函式）。
