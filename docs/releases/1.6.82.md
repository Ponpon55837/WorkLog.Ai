# Work Intelligence 1.6.82 更新說明

應用程式與 Agent plugin 版本為 1.6.82。資料庫升級到 schema 40，第一次啟動時會自動升級；升級前的備份照常保留。

## 審查完成後看得到知識頁的進度

Agent 處理完審查請求後，會接著更新受影響的知識頁。以前 Web 上看不到這一步，現在「Agent 審查請求」區塊會在請求完成後列出這些知識頁：

- 每一頁顯示目前的狀態：已更新、已檢查、仍待更新或未變動。
- 上方顯示「已更新或已檢查：2 / 5」這樣的進度。
- 點「開啟頁面」會切到知識頁分頁並打開那一頁。

有新的審查請求還在進行時，區塊只顯示新請求，不會列出上一次的知識頁。建立請求時的說明也補上一句：審查完成後，Agent 會接著更新受影響的知識頁。

## 清單在完成時保存

請求完成的那一刻會保存當時的知識頁清單（schema 40）。之後 Agent 更新了某一頁、讓它離開待更新佇列，清單也不會少掉這一頁，狀態會變成「已更新」或「已檢查」。schema 40 之前完成的請求沒有保存清單，會改用即時計算的清單。

匯出與匯入都包含這份清單。Agent 收到的 MCP 回傳格式不變，不需要重新連線。
