# Work Intelligence 1.5.0 更新說明

日期：2026-10-11。應用程式、Claude Code／Codex plugin 均為 1.5.0；資料庫 schema 30。

## 工作資訊與報告

- 總覽聚合既有工作提醒，保留來源失敗、部分資料與完整資料的區別；可隱藏此次提醒、七天後再提醒或復原。提醒偏好不會把來源任務結案，來源更新時會重新顯示。
- Session「可能相關」依同專案共同檔案提供最多五筆查閱提示；不自動建立關聯，內容增加12px內距及窄畫面換行。
- 報告段落支援釘選、隱藏／恢復及標題／內容改稿，各報告版本保留獨立修訂與引用。衝突保留草稿，需比較最新版後再套用。
- 基本報告及目前整理版可先預覽再複製 Markdown；複製失敗仍可選取文字或下載。來源失效及版本變更會阻止輸出過期內容。
- 每週洞察使用完整期間統計，呈現驗證狀態、專案分布及對應報告入口。

## 寬度與互動修正

所有頁面使用側欄旁的完整可用寬度與相同內距，切換工作圖譜時不再忽然放大或縮窄。主捲動容器預留穩定捲軸空間。

時間軸初開、期間／專案切換及清單返回圖表會自動符合整個區間；手動縮放後調整視窗保留視角。活動熱度置於總覽首屏，完整53週依容器調整並保留日期報告入口。

Knowledge／決策寫入成功後，背景讀取取消不再誤報保存失敗；整理請求按鈕在已載入目前專案資料的背景刷新時仍可操作。

## MCP 精準讀取與圖表

`work_get_session` 可選 completion／handoff 用途或18個固定欄位群組；省略新參數維持原完整回應。固定識別與安全旗標仍保留，未選欄位不做重型SQL讀取，缺少的歷史資料與未讀欄位分開標示。

三組整合任務的固定參考tokenizer量測，中位數降幅為30.39%–30.77%；小型handoff反而增加4.16%–4.49%，適合維持完整讀取。量測包含啟動契約與補查，不能代表帳戶扣款或Codex host的實際注入方式。[方法與限制](../mcp-read-projection-plan.md)。

新圖表只接受明確的architecture JSON v1；Web移除Mermaid／KaTeX執行依賴。歷史圖表的來源、ID、版本及作廢／復原稽核仍保留，可安全閱讀、複製、下載及匯出匯入。沒有批次改寫歷史圖表，也不宣稱可無損轉換所有圖表語意。

## 升級

先備份目前資料，再更新程式與依賴並建置。從1.4.0發布版升級會套用主線的migration 28–30；本次MCP投影與圖表移除沒有另外增加migration。

```bash
pnpm db:backup
git pull --ff-only
pnpm install --frozen-lockfile
pnpm build
```

重新啟動既有服務，並在Agent端重新連線Work Intelligence MCP。以 `/api/health` 核對應用1.5.0與schema30；登入服務操作見[服務指南](../service.md)。
