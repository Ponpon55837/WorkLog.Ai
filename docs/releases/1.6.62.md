# Work Intelligence 1.6.62 更新說明

應用程式與 Agent plugin 版本為 1.6.62。資料庫 schema 為 33，本版不需 migration。

## 相依套件更新

| 套件 | 更新 | 用途 |
| --- | --- | --- |
| Vue | 3.5.42 → 3.5.45 | Dashboard |
| Electron | 45.3.2 → 45.3.4 | 桌面 App |
| Vite | 6.4.6 → 8.3.8 | Dashboard 建置與開發伺服器 |
| ESLint | 10.14.0 → 10.15.0 | 程式碼檢查 |
| `@types/node` | 24.19.2 → 26.6.6 | TypeScript 型別檢查 |

Vite 8 的預設建置目標為 Chrome 與 Edge 111、Firefox 114、Safari 16.4。使用外部瀏覽器開啟 Dashboard 時，可依這組版本核對環境。[Vite 8 遷移文件](https://vite.dev/guide/migration#default-browser-target-change)

`@types/node` 26 移除了 `path.PlatformPath`。桌面儲存風險檢查與 Agent 整合記錄改由 TypeScript 從實際使用的 Windows／POSIX 路徑 API 推斷型別。以原始碼或 standalone 方式執行仍支援 Node.js 22.16 以上的 22.x 或 24 以上。

## 測試與文件

- 桌面單元測試與 coverage 共用 Electron mock 解析。使用 mock 的測試可在未下載 Electron 執行檔的環境執行。
- 英文及繁體中文 README、Agent 設定與疑難排解文件已依桌面 App 的操作流程更新。

## 升級

桌面 App 可在「設定」分頁的「更新」卡片檢查新版。依使用的安裝方式參考[更新 Work Intelligence](../user-guide.md#更新-work-intelligence)。既有資料可直接開啟。
