# Work Intelligence 1.6.96 更新說明

應用程式與 Agent plugin 版本為 1.6.96。資料庫維持 schema 43。

這一版整理專案的「資料備份」分頁（#489）。

## 先說明該用哪一種

分頁最上方說明兩種情況：換電腦或合併兩台電腦的記錄，用「匯出專案資料」與「匯入專案資料」（JSON）；整台電腦損壞要整份還原，用「匯出整份資料」（.sqlite）。匯出與匯入分成兩個區塊。用指令還原 .sqlite 的步驟收進「進階：用指令還原」；桌面 App 則照舊在「資料」分頁還原。

## 選檔更順手

匯入改用「選擇檔案」按鈕，會顯示選到的檔名，也可以直接把 .json 檔拖進匯入區塊。不是 .json 的檔案會直接拒絕，不會清掉已經在預覽的檔案。預覽完成後，畫面會捲到預覽並把焦點移過去。

## 看得懂預覽數字

新增、將更新、保留本機、略過、衝突各有一行說明，「各類型明細」可以看每種資料的數量。「確認並匯入」改成一般寬度的按鈕。

會不會寫入改由伺服器判斷：

- 沒有任何資料要寫入時，顯示「沒有需要匯入的變更」和「完成」。
- 差異全是衝突時，說明原因：例如在「只新增」下匯入的資料較新，可以改用「較新者優先」；找不到資料夾時，請在上方為專案選擇位置。

## 匯入之後

匯入結果顯示在匯入區塊裡，並提供「前往專案清單」。
