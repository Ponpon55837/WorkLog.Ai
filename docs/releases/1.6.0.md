# Work Intelligence 1.6.0 更新說明

日期：2026-10-16。應用程式與 plugin 版本為 1.6.0；資料庫 schema 維持 30。

## 讓資料庫成長更慢

- **備份保留份數降為 3**：手動備份、每日自動備份、刪除 Session 前的快照預設各保留最近 3 份（原本 14／14／5）。`WORK_INTELLIGENCE_BACKUP_KEEP` 仍可調整手動備份份數。超過新上限的舊備份，會在下次寫入備份時清除。
- **清理 workSummary 更新歷史**：`session_work_summary_updates` 的前後 workSummary 只用於 Agent 以相同 `idempotencyKey` 重試時重播回應，卻佔了該資料表約四分之三的空間。超過 7 天的紀錄會清空這兩個欄位；請求內容與紀錄本身保留，所以相同 key 搭配不同內容仍會回傳 conflict。
- 清理在 API server 啟動時執行一次，之後隨每小時的備份檢查執行；不需要 migration，也不會自動執行 VACUUM。想讓檔案立即變小，可在停止 server 後執行 `pnpm db:maintain`。

## 行為變化

重試一個已被清理的舊 `idempotencyKey` 時，回傳 `work_summary_updated` 與 `duplicate: true`，內容是 Session 目前的 workSummary，不含 `previousWorkSummary`，不再回 `not_found`。匯出／匯入與遮罩照常運作，匯入 `{}` 是合法值。

## 升級

```bash
pnpm db:backup
git pull --ff-only
pnpm bootstrap
```

本次不新增資料表或 migration。如果有安裝登入自動啟動服務，請依提示重啟服務；Agent MCP 的工具沒有變更，不需要重新連線。
