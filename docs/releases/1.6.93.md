# Work Intelligence 1.6.93 更新說明

應用程式與 Agent plugin 版本為 1.6.93。資料庫維持 schema 43。

這一版整理 Web 的未結項清單（#486）。

## 清單更緊湊

每筆未結項只占內容加一行來源資訊，「標記完成」與「標記不再需要」收成列尾的圖示按鈕；手機上按鈕排在第二行靠右。只有不是看「待處理」時才顯示狀態標籤。手機版清單不再擠在固定高度的框裡，而是跟著頁面捲動。

## 立即生效，可以復原

完成、不再需要與重新開啟都立即生效，提示訊息裡有「復原」，約 8 秒內可以撤回；滑鼠移到提示上或用鍵盤停在提示上時會暫停倒數。批次操作也一樣。期間如果有項目在別處被改過，會跳過那些項目並告訴你更新與略過各幾筆，不會整批失敗。

## 一次選取全部

勾選「選取本頁」後可以按「選取全部 N 筆」，跨頁選取所有符合篩選的待處理項目。批次按鈕只在有選取時才出現。

## 更容易找到未結項

側欄新增「未結項」與待處理數量（快捷鍵 g o），分頁第一次載入就顯示數量。「整理未結項」不必先選專案，會列出有待處理項目的專案與數量；Agent 已結案的清單也改成同樣緊湊的排版。
