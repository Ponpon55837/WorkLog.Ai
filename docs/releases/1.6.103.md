# Work Intelligence 1.6.103 更新說明

應用程式與 Agent plugin 版本為 1.6.103。資料庫維持 schema 43。

這一版修正永久刪除的 Session 在匯入時又出現的問題（#513）。

## 已永久刪除的 Session 不會再被匯入帶回來

你在這台電腦永久刪除一個 Session 後，若匯入較舊的匯出檔，或另一台電腦的匯出檔（那邊還留著這個 Session），它以前會再次出現。現在匯入預覽與實際匯入都會把這個 Session 列為「已在本機刪除」的衝突，原因寫明「Session 已在本機永久刪除，匯入不會把它加回」，並且不會寫入。即使另一台電腦在你刪除之後又修改過它，結果也一樣。

這個 Session 的決策、待結項與其事件、證據、連結、圖表等關聯資料也不會加入，會顯示為依賴上層而被略過的衝突。判斷只看 Session 的 ID；另一台電腦重新建立、ID 不同的 Session 照常匯入。匯出檔格式與資料庫都沒有變。

知識、知識候選與知識頁的檢查位置如果引用了這個已刪除的 Session，仍會正常同步，只是不再帶著那筆引用，和本機刪除時的處理一樣。決策的審查項目與決策提醒偏好不會加回；若某個待結項事件只是以這個 Session 為執行者，會照常匯入。

## 只剩已刪除的資料時，預覽不再說「目前設定下沒有可匯入的變更」

如果匯入預覽中唯一的衝突是已在本機刪除的 Session 或知識頁（以及它們底下的資料），畫面現在會顯示「沒有需要匯入的變更」，並註明有幾筆資料已在這台電腦刪除、不會再匯入，不再誤以為是被設定擋住。
