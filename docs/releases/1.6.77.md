# Work Intelligence 1.6.77 更新說明

應用程式與 Agent plugin 版本為 1.6.77。這一版只調整 Web 畫面，資料庫維持 schema 38，Agent 不需要重新連線 MCP。

## Agent 審查請求會告訴你下一步

按下「請 Agent 處理」之後，通知與「Agent 審查請求」區塊都會寫明：在 Claude Code 或 Codex 說「處理 Agent 審查請求」即可。這和「更新知識頁」「整理 Knowledge 候選」的提示方式一致。

## 用量頁的版面

- 左側的專案與期間區塊在分欄時會撐滿到畫面底部，專案清單使用期間、進階設定與「掃描用量」按鈕以外的全部高度。專案很多時只捲動清單，按鈕維持在畫面上。視窗較窄、改為上下排列時，清單維持原本的高度上限。
- 同一列的面板高度一致：用量數字卡片與「5 小時區段」底部對齊，「每日趨勢」與「Token 組成」底部對齊。
