# Work Intelligence 1.6.65 更新說明

應用程式與 Agent plugin 版本為 1.6.65。這一版沒有資料庫 schema 變更，資料庫維持 35，專案匯出檔格式與 1.6.64 相同。

## 升級後一鍵更新資料庫

- 以前升級桌面 App 後，如果資料庫需要更新結構，狀態會顯示「版本不支援」，而且「重試啟動」不會更新資料庫，只能用「選擇資料庫…」自己找到同一個檔案再同意更新。
- 現在這種情況顯示「需要更新資料庫」，「狀態」與「資料」分頁直接提供「先備份再更新資料庫」。按下後 App 會重新檢查檔案、先備份，再更新並啟動服務。這段期間「重試啟動」改為次要按鈕。
- 資料庫在雲端同步資料夾、卸除式磁碟或硬連結上時，不提供原地更新，改提供「複製到本機資料夾後更新」：確認後複製到預設資料夾、更新複本並切換過去，原檔不會被改動。
- 只有資料庫是由較新版本的 App 建立時，才會顯示「版本不支援」。

## 顯示語言

- 桌面 App「設定」分頁最上方新增「顯示語言」：跟隨系統（預設）、繁體中文、English。視窗、系統匣選單、macOS 應用程式選單與對話框立即切換，不必重新啟動。
- App 管理的 Dashboard 使用同一個語言：Dashboard 開啟或重新整理時跟上 App 的設定，在 Dashboard 改語言也會改 App 的設定。
- 語言選擇存在 App 設定檔旁的獨立小檔案，舊版 App 不會讀它，退回舊版不會要求修復。檔案損壞時視為「跟隨系統」，不會讓 App 無法啟動。

## Agent 知識頁維護指引

- Work Intelligence skill 的知識頁指引新增三個步驟：檢查並更新時維持 `review` 讀取，只有使用者要求完整重寫才改用 `full`；context 為 `truncated` 時再讀一次，直到沒有 `new` Session；內容沒變就用 `work_mark_knowledge_page_checked`，不重存相同段落。
- 這三步經過 A/B 驗證：在虛構的合成專案上，知識頁情境的通過數從 7/10 提高到 10/10，Token 與回合數沒有明顯下降。每個情境只跑 2 次，結果是方向性的證據，不是穩定的效果大小。
- 檢索指引的修改沒有帶來改善，不採用，也不做導航讀模型。完整數字見 `docs/experiments/retrieval-baseline/ab-report.md`，決策見 `docs/decisions/2026-11-agent-guidance-ab.md`。

## 升級

桌面 App 可在「設定」分頁的「更新」卡片檢查新版。依使用的安裝方式參考[更新 Work Intelligence](../user-guide.md#更新-work-intelligence)。更新 Agent plugin 後，Agent 回報 `restartRequired` 時請重新連線 Work Intelligence MCP。
