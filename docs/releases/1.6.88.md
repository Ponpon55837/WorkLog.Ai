# Work Intelligence 1.6.88 更新說明

應用程式與 Agent plugin 版本為 1.6.88。資料庫仍是 schema 42，不需要升級。

這一版讓 Knowledge 候選的數字和實際能整理的量一致，Agent 也會一路整理到完（#481）。

## 候選頁只列值得整理的 Session，每個專案分開

以前候選頁把所有專案還沒整理過的 Session 加總成一個數字，但 Agent 每次只讀 10 筆，數字幾乎不會變小。

現在只計算值得整理的 Session：有已確認的決策、修復紀錄，或被後續工作引用，而且還沒整理過。每個專案一列，各自有「整理」按鈕；沒有可整理的 Session 時不顯示。

## Agent 交回候選後會接著整理下一批

Agent 交回一批候選時，如果這個專案還有值得整理的 Session，會自動建立下一批，Agent 接著處理，直到整理完。中途停下也沒關係，下次會從停下的地方繼續。後面的批次會看到前面已提出的候選，不會重複提出。

## 可以停止整理

等待中的整理請求旁邊有「停止」按鈕。停止後這些 Session 會回到未整理，已提出的候選不受影響。
