# Work Intelligence 1.6.100 更新說明

應用程式與 Agent plugin 版本為 1.6.100。資料庫維持 schema 43。

這一版讓 Agent 審查讀到的內容更精簡（#474 第三步）。

## 同一個 Session 只列一次

Agent 讀取審查內容（`work_get_agent_review_context`）時，以前每一筆決策與候選都附上完整的來源 Session 摘錄；同一個 Session 有好幾筆待審項目時，同一份摘錄會重複好幾次。

現在每頁另帶一份 `sessions` 清單，該頁用到的每個 Session 只出現一次，項目只標 `sourceSessionId`。Session 的「其他決策」也不再重複列出該頁已經是待審項目的決策。欄位內容與截斷標記和以前相同，回應上限沒有改變。

用真實資料實測一次完整審查（55 筆、6 頁），總字元數從約 64,200 降為約 61,300，約少 5%；同一個 Session 項目集中的頁面少 20–26%。
