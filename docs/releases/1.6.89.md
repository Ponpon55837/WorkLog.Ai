# Work Intelligence 1.6.89 更新說明

應用程式與 Agent plugin 版本為 1.6.89。資料庫升級到 schema 43，開啟時會自動升級，升級前會先備份。

這一版讓未結項不必再全部手動結案（#482）。

## Agent 整理未結項會直接結案

以前請 Agent 整理未結項後，Agent 只會提出建議，每一筆都要在 Web 上接受。現在 Agent 的判斷會直接生效，仍要附上理由與證據 Session。

「整理未結項」面板會列出 Agent 結案的項目、理由與證據；判斷錯的項目可以逐筆或整批重新開啟。升級時，還在等待審查的建議會標為未採用，項目維持待處理；從舊版匯入時也一樣。

## 已知限制可以直接記錄

範圍外說明、已知限制這類不是待辦的項目，Agent 可以標成「記錄為已知限制」，只需要理由。

## 從源頭減少不該進未結項的內容

Agent 寫工作記錄時，如果把範圍外說明、尚未在某個平台實測、或交給使用者決定的事寫成待辦，會收到提醒，改寫到成果或驗證裡。

## 寫工作記錄時更容易結案

- Agent 之後完成了自己先前留下的未結項，可以直接把它結案。
- 存檔回條會把提到相同 issue 編號或版本號的未結項排在前面，標成「可能已完成」，方便 Agent 核對。
