# Work Intelligence 1.6.86 更新說明

應用程式與 Agent plugin 版本為 1.6.86。資料庫升級到 schema 41，開啟時會自動升級，升級前會先備份。

這一版新增「專案慣例」：使用者確認過的做法，Agent 每次開工都會看到（#451）。

## 把 Knowledge 設為專案慣例

在「工作知識」的 Knowledge 清單，從列上的「更多」選「設為專案慣例」。每個專案最多 5 件，只有使用中、沒有待檢視標記的 Knowledge 可以設定。選了專案時，篩選列會顯示目前件數（例如 3/5）；滿 5 件時按鈕會停用，要先取消其中一件。設定或取消不會改變 Knowledge 的更新時間和排序。

## Agent 開工時會看到

Agent 讀取這個專案的上下文時，會收到專案慣例的標題清單，需要時再讀全文。這份清單不受任務內容影響，也不會擠掉原本和任務相關的內容；有慣例時，回應最多多出 700 字元。專案沒有設定慣例時，回應和以前完全一樣。

## 內容改變時自動撤回

以下情況會自動撤回專案慣例，列上會顯示撤回原因、由誰造成和時間，確認內容後可以按「重新確認為專案慣例」：

- Knowledge 被封存或被新的 Knowledge 取代。
- 有工作回報它已不成立，或它被標成需要檢視。
- Agent 修改了標題或內文（只改標籤或確認仍有效不會撤回）。Agent 會收到提醒，並告訴你這件事。
- 從另一台電腦匯入的較新版本改了標題、內文或狀態。

Agent 不能設定專案慣例，只有你能在網頁上設定。

## 匯出與匯入

匯出檔會帶上專案慣例。匯入時，本機已有的 Knowledge 保留本機的設定；新的 Knowledge 會帶入設定，但同樣受每個專案 5 件的限制，超出的會撤回，匯入預覽會列出件數。舊版的匯出檔仍可匯入。
