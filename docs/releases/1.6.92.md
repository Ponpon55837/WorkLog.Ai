# Work Intelligence 1.6.92 更新說明

應用程式與 Agent plugin 版本為 1.6.92。資料庫維持 schema 43。

這一版統一 Web 上「交給 Agent 處理」的流程（#484）。

## 每個交給 Agent 的地方都長得一樣

Agent 審查、知識頁、Knowledge 候選、未結項整理、補齊工作記錄資料與報告，按下請 Agent 處理後都會出現同一個提示區塊：目前狀態、一句說明接下來會發生什麼、可以直接複製給 Agent 的那句話；可以取消的流程也在這裡取消。提示訊息只負責告訴你請求已建立。

## Agent 審查不必先選專案

沒有選專案時，Agent 審查會列出有待處理項目的專案和各自的數量（決策、候選、Knowledge），每個專案各有一個按鈕；只有一個專案時直接顯示按鈕。進行中的請求全部列出，各自可以取消。整理候選選單也會顯示每個專案的待處理數量。

## 停用的按鈕說明原因

停用的按鈕改成灰色，滑過時說明為什麼不能按。已經要求更新的知識頁顯示「已要求」，不會重複送出；只追蹤一個專案時，「自訂知識頁」不必先選專案。讀取失敗時會顯示錯誤並可以重試。
