# 決策紀錄：降低 Agent 固定閱讀量（1.6.78 A/B）

- 日期：2026-11-26
- 狀態：已決定，已隨 1.6.78 發行
- 範圍：伺服器 instructions、核心 skill、操作索引、`work_get_context` 與 `work_finalize_session` 合約、結案回條、結案請求檢查、知識頁 reviewToken 檢查
- 設計：[`2026-11-agent-reading-budget-design.md`](2026-11-agent-reading-budget-design.md)
- 證據：[`runs-1.6.78.json`](../experiments/reading-budget-ab/runs-1.6.78.json)、[`runs-1.6.78-review.json`](../experiments/reading-budget-ab/runs-1.6.78-review.json)

## 背景

1.6.74 的固定閱讀量是 42,249 / 42,250 字元，下一個需要加指引的功能會直接撞到上限（Issue #440）。這次把伺服器會拒絕、會自動處理，或回條會提示的規則移出固定閱讀，上限不調高。

## 做法

A 臂是 1.6.77（main），B 臂是 1.6.78。兩臂用同一份虛構專案與逐字相同的 Agent 提示，只有伺服器送出的 instructions 與合約不同。每格 3 次，判定條件在執行前寫進 `harness.mjs`。

## 證據

固定閱讀量：42,244 → 30,099 字元（−29%）。

| 情境 | 1.6.77 | 1.6.78 |
|---|---|---|
| A1 一般結案（8 項條件） | 3/3 | 3/3 |
| A2 未登錄、暫停、忽略的專案 | 0/3 | 3/3 |
| A3 含機密與不該記錄的聯絡資訊 | 3/3 | 3/3 |
| A4 結案未結項、回報 Knowledge、附圖 | 11 項過 10 項 ×3 | 11 項過 10 項 ×3 |
| A5 知識頁儲存遇到版本衝突 | 3/3 | 3/3 |
| A6 讀不到 resource，只靠工具回應 | 記錄 1/1，略過 0/2 | 記錄 3/3，略過 2/2 |

- A2 與 A6 的略過情境在 1.6.77 不通過，原因都是 Agent 在確認追蹤狀態之前先執行 `git status` 或列目錄；沒有任何一次寫入資料或改記到同名專案。B 臂最初的措辭同樣不通過（6 次中 0 次）。把 instructions 改成明列 git、列目錄、搜尋、讀檔都要等 `work_get_context` 之後，同一個模型由 0/3 變為 3/3。
- A4 兩臂都沒有自動附上架構圖，其餘 10 項（未結項的完成、取代、保留，Knowledge 回報）全過。這一項不是本次造成的，另外追蹤。
- A5 的讀取量平均由 65,277 降到 49,065 字元。
- A6 的記錄情境中，B 臂有一次以腳本連送 116 次結案來猜 `workSummary` 的欄位名。兩臂的驗證錯誤當時都沒有指出是哪個子欄位。改為帶出子欄位後重跑 3 次，都在 3–4 次拒絕內完成。
- 合法請求重放：測試以固定種子產生的合法請求在新舊檢查下結果一致。另外在一份真實資料副本上，把 718 筆未作廢的記錄還原成結案請求送進 1.6.78，718 筆全數寫入、沒有任何一筆被拒絕；該副本中也沒有 `startedAt` 晚於 `completedAt`，或同一筆 Knowledge 同時被同一筆記錄回報為有用與有誤的資料。還原的請求不含當時的未結項與 Knowledge ID 清單，這兩類只由前述的資料檢查與種子測試涵蓋。

## 決定

- 採用 1.6.78 的精簡內容與新的預算上限（各部分為實測值加約 10%）。
- instructions 保留明列「哪些動作要等 `work_get_context`」的句子，即使它讓固定閱讀量多 133 字元。
- MCP 的驗證錯誤一律帶出子欄位。
- 四種自相矛盾的結案請求改為拒絕；未知或其他專案的 ID 維持警告。
- 知識頁儲存檢查 reviewToken 的涵蓋點；Web 手動編輯的涵蓋方式不變。

## 回退方式

各項可以分開回退：instructions 的句子、合約與 skill 的文字、結案請求檢查（`finalize-request-checks.ts`）、reviewToken 檢查（`isReadPoint`）互不相依。回退文字時要同步兩份 plugin 內的 skill 與預算測試的上限。

## 重新評估的條件

- 修改 instructions 的追蹤句或核心 skill 的追蹤規則時，重跑 A2。
- 固定閱讀量再次接近上限時，先找可以移到伺服器檢查或回條的規則，不調高上限。
- 調整附圖提示時，以 A4 的附圖條件為準。
